# NEXUS

Organizador personal inteligente impulsado por IA (PHP + MySQL + Groq).

## Instalación
1. Copia `includes/config.example.php` a `includes/config.php` y pon los datos de tu base de datos.
2. Copia `includes/ia_clave.example.php` a `includes/ia_clave.php` y pon tu clave de Groq.
3. Sube todo a un hosting con PHP y MySQL.
